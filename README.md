# Yash Chaturvedi — Portfolio

My personal portfolio: projects, skills, and résumé.

**Live:** https://yash-chaturvedi-portfolio.vercel.app/

## Built with

- **TypeScript + Vite**: the whole site, with no framework, built and bundled by Vite.
- **WebGL**: the interactive 3D core in the hero (`src/scene.ts`), lazy-loaded.
- **HTML + CSS**: layout, the dark and light themes, and the animations, including the gesture-control demo.
- **Self-hosted fonts**: Instrument Sans/Serif and DM Mono for type.
- **AVIF/WebP images**: responsive project screenshots.
- **Vercel**: hosting and auto-deploys from `main`.

## Run locally

```bash
npm install
npm run dev
```
