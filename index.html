FRIDAY

Local AI desktop agent

Problem
Natural-language desktop tasks usually leave the machine. This agent had to drive a browser and Windows tools locally.
Built
Electron, React, and TypeScript, with Ollama on the machine and Playwright on the browser. Tool orchestration, task tracking, and a floating orb UI.

CineCircle

Social movie platform

Problem
Finding films, keeping a watchlist, and talking about them were split across products.
Built
React 19 and TypeScript, Spring Boot 3 with Spring Security and JWT, Postgres, and TMDB. Watchlists, history, ratings, reviews, follows, and genre-based recommendations. Docker for the API. The client is live on Vercel.
Decision

Gesture Control

Hands-free desktop control

Problem
A pointer, a click, and a drag, driven by a hand in a webcam frame.
Built
Python, OpenCV, and MediaPipe track the hand. PyWin32 moves the cursor. Tkinter is the UI. PyInstaller packages the app. Pinch-to-click and drag-and-drop.
Decision
Calibration is personal. Gesture thresholds are fit to the person in frame instead of one global cutoff.
